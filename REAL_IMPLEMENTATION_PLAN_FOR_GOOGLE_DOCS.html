1. Architecture and Stack

DomainRecommendationReason / Details
App TypeSingle PWA web app, not nativeMobile-friendly, no Play Store delay, low data use, one codebase for shop plus admin
FrontendNext.js App Router plus Tailwind CSSSEO for catalogue, route groups for shop and admin, PWA-ready, fast iteration
Backend / DatabaseSupabase Postgres with Row Level SecurityTransactions for reserve and release, isolates customer vs admin data, free-tier friendly

RejectedFlutter / Firebase, WordPress / WooNative overhead, or hacky stockpile and fee and never-merge logic

DomainRecommendationReason / Details

3. Core Business Logic

DomainRecommendationReason / Details
TotalsSum variant price times qty plus addons minus credit, integers in NGNAuto calc, live cart total, no float errors
ConfirmOne DB transaction: insert order from pending, decrement available, increment reserved, notifyAtomic Confirm to ID to Reserve, abort on race
UnderpaymentNo Order ID, show outstanding, one top-up linked, expire in 7 days to RejectedBlocks processing, gives recovery path
OverpaymentConfirm plus ID plus reserve, excess to auto credit unless over 50k for manual reviewMeets policy, handles large cases
Retaining FeeFree until equals confirmed date Africa Lagos plus 14 days 23:59. Extra days times daily rate. Default 500 NGN per day, bulky e.g. freezer 2000Per Order independent, transparent breakdown
Release RuleBlock Ready and Out for Delivery if fee unpaid, fee keeps accruingEnforces no-release rule
CancellationCustomer requests, admin approves only, paid converts to credit, stock returns, accrued fee due unless waivedNo auto cash refund
RecoveryAdmin search by date amount ref phone, masked list, secondary checklist 4 of 6 must match then discloseManual 2-step, no OTP, no auto reveal
